# 100Б Карьера

Одностраничный showcase-лендинг для внутреннего ознакомления с проектом «100Б Карьера»: что это за карьерное медиа, для кого оно, какую ценность даёт, как выглядит айдентика и какие форматы контента могут выходить в канале.

## Запуск

```bash
npm install
npm start
```

После запуска сайт будет доступен по адресу:

```text
http://localhost:4173
```

## Проверка

```bash
npm test
```

Сайт сделан как лёгкая статическая страница без тяжёлых зависимостей.
